# Laufartefakte hier ablegen – relevant-news V1.8

Dieser Ordner ist für Outputs aus Testläufen gedacht.

Beispiel:

```text
20_LAUFARTEFAKTE/2026-05-14_Morgen/
```

Dort ablegen:

- Setup-Validierung,
- CMO-Control-Board,
- Kandidatenliste,
- Quellenbasis,
- Shortlist-Scorecard,
- Claim-Ledger,
- Source Verification,
- Watchlist,
- Briefing-Draft,
- Adversarial Review,
- Qualitätslog,
- Management-Status,
- Korrekturtickets.

Wichtig:

```text
Laufartefakte sind Outputs, keine aktiven Regeln.
```

Sie dürfen für Evaluation gelesen werden, aber nicht als Stilvorlage für künftige Briefings dienen.
