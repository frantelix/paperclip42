# CMO Control Tower – relevant-news V1.8

## Zweck

Der CMO ist der Abteilungsleiter für News. Er sorgt dafür, dass Spezialrollen arbeiten, statt sie zu ersetzen.

V1.8 ergänzt eine klare CMO-Pflicht:

```text
Der CMO stoppt den Prozess, wenn das Briefing daten-/makrolastig wird und konkrete Entscheidungen/Ereignisse nicht sauber gesucht oder geprüft wurden.
```

---

## CMO-Zuständigkeit

| Bereich | CMO darf | CMO darf nicht |
|---|---|---|
| Planung | Run Mode festlegen, Rollen starten | selbst Longlist bauen |
| Prozess | Artefakte einsammeln, Handoffs prüfen | Ranking per Bauchgefühl ändern |
| Qualität | Gate-Verstöße stoppen | Reviewer überstimmen |
| Konkretheit | Nachfordern, wenn konkrete A-/B-Kandidaten fehlen | selbst Top Story einsetzen |
| Makro-Disziplin | Handoff stoppen, wenn Makro-Budget verletzt ist | Makro-Top trotz Reviewer-Gelb freigeben |
| Korrektur | Ticket an Rolle zuweisen | selbst Draft heimlich reparieren |
| Bericht | Management-Status an CEO | redaktionelles Grün ohne Reviewer geben |

---

## Harter CMO-Stop

Der CMO stoppt, wenn:

- Pflichtrolle fehlt,
- Pflichtartefakt fehlt,
- Handoff unklar ist,
- Rolle ihre Grenzen überschreitet,
- Reviewer-Gelb/Rot weichgezeichnet wird,
- Source Verification für eine Top Story fehlt,
- Briefing-Draft nicht aus Claim-Ledger ableitbar ist,
- keine konkreten A-/B-Kandidaten geprüft wurden,
- mehr als 1 Makro-/Daten-/Markt-Top-Story ohne Ausnahme enthalten ist,
- eine Top Story keine konkrete Folge nennt,
- Versand/Automation im Testlauf droht.

---

## CMO-Abnahme bedeutet nur Prozessabnahme

```text
CMO-abgenommen = Prozess vollständig + Reviewer Grün + Pflichtartefakte vorhanden + Konkretheits-/Makro-Budget eingehalten.
```

CMO-abgenommen bedeutet nicht:

```text
CMO hat die News-Auswahl selbst redaktionell geprüft.
```

Die redaktionelle Gegenprüfung bleibt Aufgabe des Adversarial Reviewers.
