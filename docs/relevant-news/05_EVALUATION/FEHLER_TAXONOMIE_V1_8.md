# Fehler-Taxonomie – relevant-news V1.8

Der Reviewer soll Fehler benennen, damit Qualität messbar wird.

---

## Fehlercodes

| Code | Fehler | Typische Ursache | Gegenmaßnahme |
|---|---|---|---|
| F1 | falsches Ranking | interessante Meldung schlägt wichtigere Story | Challenger härter prüfen |
| F2 | Quelle trägt Claim nicht | Quelle nur teilweise gelesen | Claim-Ledger erzwingen |
| F3 | Claim zu stark formuliert | Writer verstärkt Quelle | Maximalformulierung nutzen |
| F4 | kein echtes Delta | Update wegen Reaktion/Kommentar | Delta-Gate anwenden |
| F5 | Reprint-only bei starkem Claim | Original/Primärquelle fehlt | Source Verification |
| F6 | KI übergewichtet | Anbieter-PR klingt wichtig | KI-Gate und Zweitanker |
| F7 | Deutschland-konkret ohne Primäranker | Agenturmeldung reicht nicht | Behörde/Gesetz/Ministerium prüfen |
| F8 | internationale Balance nur formal | Regionen genannt, aber nicht verglichen | Challenger aus Regionen erzwingen |
| F9 | Watchlist schwach | keine Trigger, nur Parkplatz | Watchlist-Gate |
| F10 | Makro und Top Stories vermischt | Datenblock ersetzt News | Makro-Budget-Gate |
| F11 | Auffüllmeldung | Top 5 als Pflicht verstanden | No-Filler-Gate |
| F12 | alte/stale Story | Timing nicht geprüft | Aktualitäts-Gate |
| F13 | Rollenvermischung | Writer/Reviewer identisch oder CMO springt operativ ein | Setup korrigieren |
| F14 | Review zu weich | Gefälligkeits-Grün | Adversarial-Prompt schärfen |
| F15 | Datenqualität generisch | keine konkrete Schwäche genannt | Datenqualitäts-Pflichtfelder |
| F16 | Source Verification fehlt | Top Story nicht separat quellengeprüft | Source-Verifier-Gate |
| F17 | Cluster-Dominanz unbegründet | mehrere Top Stories aus gleichem Strang | Cluster-Budget-Gate |
| F18 | CMO-Rolle falsch genutzt | CMO ersetzt Spezialrollen | Control-Tower-Gate |
| F19 | Verb-Ladder verletzt | Quelle trägt Verb nicht | Zwei-Quellen-/Verb-Gate |
| F20 | Nicht-USA/EU nur formal geprüft | Balance-Block ohne ernsthafte Challenger | Regionen-Challenger nachfordern |
| F21 | konkrete Entscheidung verdrängt | A-/B-Meldung verliert gegen abstrakte Datenmeldung | Konkretheits-Gate anwenden |
| F22 | Makro-Budget überschritten | mehrere CPI/PPI/Öl/Markt-Top-Stories | maximal 1 Makro-Top; Rest Kontext/Watchlist |
| F23 | Bürger-/Unternehmensfolge fehlt | Top Story erklärt nur Lage, nicht Wirkung | konkrete Folge nachfordern oder herabstufen |
| F24 | Daten-/Preis-Tick aufgeblasen | Öl/Börse/Index ohne neue reale Ursache | Score-Cap 5, Kontext statt Top |
| F25 | Konkretheitsklasse falsch | Plan/Erwartung als Beschluss dargestellt | Source Verification + Verb-Ladder |

---

## Reviewer-Pflicht

Jedes Gelb/Rot braucht mindestens einen Fehlercode.

Grün darf Fehlercodes enthalten, wenn sie gering und korrigiert sind.

Bei Makro-/Datenlastigkeit mindestens F10, F21, F22, F23 oder F24 prüfen.
